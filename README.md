# Smart Grievance Redressal System

Web app for students to submit and track complaints.

## Features
- Submit complaints with auto-categorization (Hostel, Academic, Infrastructure and more)
- Urgency detection to flag high-priority complaints
- Duplicate complaint detection
- Anonymous submission option
- Unique Tracking ID to check complaint status
- Password-protected admin dashboard with category chart and status updates

## Tech Stack
HTML, CSS, JavaScript (rule-based categorization, data stored in browser localStorage)
